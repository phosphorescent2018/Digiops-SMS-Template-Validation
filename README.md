# DigiOps 短信模板字符保存校验 原型

对应需求：REQ-2026-1102-001（英文短信模板新增非法字符保存校验限制）。

## 页面

- 新建模版 / 编辑存量模版（`模板配置`）：BusinessID、模板名称、触达通道（牛信 / 短信）、内容类型（营销类 / 通知类）、插入变量、消息内容（0/1000 计数）+ 右侧手机短信预览。

## 交互

- **保存时前端校验**：内容按 GSM-7 字符集（基础集 + 扩展集）逐字符校验，命中非法字符则保存失败、红框提示，**一次列出全部不同的非法字符**（重复只列一次）并给替换建议（`—` 改 `-`、`’` 改 `'`、`…` 改 `...` 等）。
- **变量不参与校验**：`#客户姓名#` 这类变量占位符跳过字符校验；右侧预览按示例值渲染。
- **模拟后端二次校验**：保存走 `mockServer.saveTemplate`（同一份字符表），接口层再校验一次；「原型演示辅助」里的「直接调保存接口（跳过前端校验）」可演示后端返回 422 与字符清单。
- **编辑存量模板**：切换「编辑存量」会载入一条含 `—` 的存量模板，保存被拦截，把 `—` 改成 `-` 后才能保存。
